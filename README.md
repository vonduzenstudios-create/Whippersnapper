# Nocturne of Ash

**Version 0.17.1** (see the [changelog](#changelog) at the bottom)

A gothic action-platformer tech demo in the style of the classic "castle exploration" games. Everything is generated by code: sprites, tiles, 3D backdrops, sound effects and music. The project has no image or audio files.

## Run it

1. Install [Node.js](https://nodejs.org) 18 or newer.
2. In this folder run:
   ```
   npm install
   npm run dev
   ```
3. Open the URL Vite prints, http://localhost:5273.

To make a production build, run `npm run build`. The output goes to `dist/`.

`play-standalone.html` is a single-file build. It loads three.js from a CDN, so it needs an internet connection.

## Controls

| Action | Keyboard | Gamepad |
|---|---|---|
| Move / aim | Arrows or WASD | D-pad / left stick |
| Jump | Z or K | A |
| Whip (8 directions with the d-pad) | X or J | X |
| Sub-weapon | C or L | Y |
| Run (hold while moving) | Left Shift | RT |
| Raise shield (hold) | F or I | LT |
| Backdash | V | B |
| Shield bubble (needs the Ashglass Ward) | Up + C or L | Up + Y |
| Menu | Enter / Esc | Start |
| Map | Tab / M | Back |

- Hold the whip button after a strike to dangle the chain.
- Down + Jump drops you through ledges.
- Sub-weapons can be thrown while crouching, and you stay crouched.
- Hold Run while moving to run. Running leaves afterimages, but your armor doesn't count while you run.
- Hold Shield to raise your shield: you creep at 15% speed but can still jump and crouch. Hold Up + Left/Right to aim it up and forward, or Up alone to hold it overhead; while aiming up you stand still. It cuts the damage of weapon strikes and lunges from the side it faces, and stops bones, books, feathers, rocks and webs. Walking into an enemy, fire, hexes and shockwaves go straight through it and knock it down for a moment.
- In water, Jump swims upward. With your head at the surface, Jump leaps high out of the water.
- On the map: move the cursor with the stick, d-pad or arrows. Zoom with the right stick (up/down) or Q / E. Jump places an X marker, or removes the one under the cursor. Markers are saved with your game.
- Once you have the **Chain Grapple**, whip toward an iron ring to latch on. Left/Right swings, Up/Down climbs, and Jump lets go. Hold Up while jumping for a higher launch.
- At a save altar, press Up to rest (full heal) and save.
- You can rebind keys in Menu → Controls.
- After character select you pick a difficulty (Normal, Hard, Brutal). It only changes how hard enemies hit. Change it any time in Menu → Options.
- Menu → Bestiary lists every enemy you've defeated, with its stats and drops.

## Map editor

Press **F2** during play to edit the room you're in, or open `/editor.html` to start in the editor with a room picker. Left click paints tiles, places entities or drags them. Right click erases. WASD or the mouse wheel scrolls. Ctrl+Z undoes. Press F2 to test-play from the ghost hero. **SAVE** (Ctrl+S) writes your changes to `src/world/room_edits.json` while `npm run dev` is running, so they become part of the game.

## Project layout

```
src/
  main.ts            entry point
  config.ts          resolution, tile size, physics constants
  core/              input (keyboard + gamepad, rebinding), math helpers
  gfx/
    pixel.ts         software pixel painter used for all sprites
    art_chars.ts     2D bone rig → hero, enemies, the Ossuary Wyrm
    art_items.ts     pickups, candles, effects, fire
    tiles.ts         per-room tile painter (bricks, moss, spikes…)
    backdrops.ts     three.js 3D backgrounds, lights and shaders per theme
    font.ts          5x7 bitmap font
    view.ts          renderer, camera, sprite shader
  audio/
    audio.ts         Web Audio engine + synthesized sound effects
    music.ts         step sequencer, instruments, original compositions
  world/
    rooms.ts         the old castle's room layouts (built in code)
    rooms_depths.ts  the eight 0.18.0 zones
    room.ts          tile collision
  game/
    game.ts          game loop, room loading, combat, camera
    player.ts        Vesna: movement, whip, dangle, grapple swing
    enemies.ts       zombie, bat, spear knight, bone thrower, wisp, drowned
    boss.ts          Ossuary Wyrm (two phases)
    boss_base.ts, boss_<name>.ts   the newer bosses, one file each (0.19.0)
    objects.ts       candles, pickups, holy water, cross, projectiles, altars
    stats.ts / data.ts   RPG stats, items, equipment, save data
  ui/hud.ts          the status display (classic, or one of two blood-orb styles)
  ui/ui.ts           HUD, title, pause menus, map, game over
```

Rendering works like this. The game renders at 384×224 and scales up with crisp pixels. A perspective camera is placed so that the z=0 plane maps 1:1 to screen pixels. Sprites and tiles live on that plane, and the 3D castle sits behind it and gets real lighting and fog.

Debugging:
- The running game is exposed as `window.game` in the browser console. For example, `game.hunter.grapple = true` gives you the grapple.
- Add `#tour` to the URL to cycle the camera through every map cell.
- Add `#boss` to the URL to jump straight into the boss fight with debug HP.
- **TEST ENEMY** on the title menu lists every enemy, variant and boss: pick one to fight it in the Test Chamber (bosses in their own arena). F3 in the game opens the enemy editor in a new tab.
- The enemy editor's **Test this enemy** button opens the Test Chamber with that enemy (unsaved changes included), or a boss's real fight. By hand: `#test=<enemy id>`, `#test=boss:<id>`, or `#test` / `#lab` for the empty chamber. Inside: R spawns another, [ and ] switch enemies, 6 clears, 7/8/9 toggle the experimental relics, 0 refills HP and hearts.

### 0.21.0 (2026-10-03)

The Ossuary Wyrm, redrawn in the same 16-bit style as the Bell-Mother (`gfx/art_wyrm.ts`).

- **No more rotated sprites.** The Wyrm's skull and vertebrae used to be one drawing each, turned and scaled by the GPU, which smeared the pixels and turned the shading with them. Now every piece is drawn again for each of 32 headings (`WYRM_DIRS`), so the pixels stay crisp and the light always falls from the same side of the screen. The boss picks the frame nearest to a piece's heading (`wyrmDir`) and never rotates, flips or scales a sprite.
- **The skull**: form-shaded bone (ivory in the light, bruised violet-brown in shadow), ringed horns, cracks, a long front fang, a fire in the eye socket, and four jaw positions instead of three. Heading left it is mirrored top to bottom as it is drawn, so the horns stay on top.
- **The body**: vertebrae seen flat like a snake's skeleton (a spool with a ridge, ribs or spurs swept back on both sides), so the body never looks upside down. Drawn at four sizes down the tail instead of being scaled.
- The fight itself is unchanged. The old sheet is gone from `gfx/art_chars.ts`; there is a second sheet, `wyrmBody`. `/bosses.html?only=wyrm` shows both.

### 0.20.0 (2026-10-03)

A first try at 16-bit quality boss art, on the Bell-Mother only (the other bosses follow if this look is right).

- **Form shading** (`gfx/form.ts`). `FormCanvas` paints rounded volumes instead of flat colors: each pixel remembers its material and how much light falls on it, and becomes a color at the end, picked from the material's hand-made ramp (five or six steps, shadows leaning violet, lights leaning warm). On top of that it adds a contact shadow where one part overlaps another, a cool rim light on the edge away from the key light, and an outline tinted by the material it borders.
- **The Bell-Mother is a jointed puppet** (`gfx/art_bellmother.ts`). She has a skeleton (spine, neck, arms, bird legs, two wings of three bones each with flight feathers and coverts hung from them) and every frame is a pose computed from a clock. The wing beat is 12 in-between frames: a hard stroke down with the wing spread, then it folds at the wrist and lifts, with feather tips, hair, tail and legs trailing behind the motion and her body riding the beat. 40 frames in all (192×152 cells): `fly`, `cast`, `dive`, `fall`, `stunned`.
- Her look now matches her portrait: pale lilac skin, violet-black plumage with ash tips, gold eyes, a feather crest, the bronze bell at her throat.
- In the fight she keeps beating her wings while she sings, tumbles with her wings torn upward when her voice breaks, and slumps on the floor heaving for breath while stunned (the old sprite was one frame turned on its side).
- The old Bell-Mother drawing code is gone from `gfx/art_bosses.ts`. `/bosses.html?only=bell` shows the new sheet.

### 0.19.0 (2026-10-03)

Every boss but the Wyrm reworked, after the first playtest of 0.18.0 found them repetitive: long health bars, minion swarms, things raining from the sky, targets floating out of reach. Now each fight is a cycle you learn that opens a short window, and only blows landed in a window count (a boss's HP is a few segments, four blows each).

| Boss | The fight |
|---|---|
| Sump Leviathan | Armored while its pool is full. Whip both sluice wheels open (three strokes each) to drain it and strike the belly. It refloods; the wheels are harder to reach each round. After three drains it smashes the wheels and floods the room for good: catch the ring on the harpoon in its back, ride it (lean with the direction keys, Jump lets go) and drive it onto the three spike racks. |

### 0.17.0 (2026-10-02)

Chain grapple, reworked to feel like Super Castlevania IV:

- Hold ATTACK to hang from a ring, let go to fly off. JUMP lets go with a small hop along the way you're already moving. The release carries the swing's momentum: let go near the bottom or on the way up and you spring off it, higher the faster you were swinging.
- Up and Down reel the chain in and out again, but smoothly and over a much shorter range (20–46 px). Rings can be caught from a little less far away, and swings and launches are a touch slower. It reels quickly while you hang still and much more slowly mid-swing. Left/Right pump the swing.
- Nothing snags the swing: while you're on the ring you pass straight through walls and floors, so you never swing into the ground and stop. However you come off the ring inside a wall (letting go, or knocked off by a hit), you pop out to the nearest open spot, and a safety net frees you if you ever end up stuck inside a wall.
- Hooking a ring from above no longer throws you off to the side: the chain goes slack and you drop until it pulls taut.
- The Ringing Climb has a second ring per climb (low ring, then a high ring, then the landing).

### 0.2.0 (2026-10-02)

**Map**
- The map has a cursor. Move it with the stick, d-pad or arrows, and zoom with the right stick (up/down) or Q / E.
- Jump drops a small X marker at the cursor, or removes the one already there. Markers are saved.
- Confirm no longer closes the map. Use Cancel, Map or Pause.

**Hero**
- Running (double-tap and hold) is faster: 1.5× walking speed, up from 1.25×. It leaves a trail of fading blue afterimages.
- While running, armor counts as 0, so hits hurt more.
- Swimming: Jump in water kicks you upward. With your head at the surface, Jump leaps out higher than a normal jump.

**Combat**
- Difficulty select after character select. Normal (1×), Hard (1.5×) or Brutal (2×) enemy damage. Enemy health doesn't change, and spikes always deal the same damage.
- The pause menu's SOUND tab is now OPTIONS (music, effects, difficulty).

**Bosses**
- The Ossuary Wyrm's tail no longer stays on screen after its final explosion.
- The Bell-Mother's and Gnarlfang's death explosions now stop. The bosses used to keep exploding forever after dying.
- Boss rewards now drop a short way from you, inside a column of light. They come with a chime, a message and a bouncing arrow (it points from the screen edge when the reward is off screen). A reward you leave behind keeps its beacon.
- The Bell-Mother has been redrawn as a harpy queen, with an hourglass figure and full bust. She wears a torn feather-and-silk corset, a feather crown, long silver hair and a bell pendant.

**Enemies**
- Frost crawlers now cling to ceilings in the Aqueduct (Ice Conduit, Frozen Cistern, Aqueduct Span, Frost Sluice, Forgotten Drain) and drop when you pass below.

**Levels**
- No more invisible ceiling outdoors. Where there is no room above, the sky is open.
- A cell of open sky was added above Shattered Slope, Pilgrim's Road, Ravenwatch Cliffs, the Moonlit Drawbridge, the Windswept Spire and the Rampart Walk. Each has secret ledges, mostly reached with the double jump. The Drawbridge's castle facade hides a cracked-wall pocket.
- New minor upgrades hidden in secret spots: Might Seed (STR +1) and Ward Seed (CON +1).
- Tides in the Rimeworks Aqueduct. The odd floating pools are gone. The Ice Conduit and the Frozen Cistern now flood and drain on a 15-second cycle, with a rumble and a message when the water starts to move. At high tide you can swim up and leap to places a jump can't reach: the Conduit's high shelf, and a sealed tank under the Cistern bridge (you enter it through a hole in its floor). Signs teach swimming.

**Visuals**
- The moon is round in every room. It used to stretch into an egg in wide rooms, like the Windswept Spire and the Hound Pit.
- Aqueduct water is icy blue instead of crypt green.
