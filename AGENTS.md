# Nocturne of Ash: agent guide

A browser tech demo of a 2D gothic action-platformer, meant as a slice of a much larger game (no ending, no final boss). Character select (Vesna or her twin Anzel, cosmetic only), an avalanche-chase prelude through a mountain pass (5 rooms, with an opening cinematic), an interconnected castle (14 rooms) ending at the Ossuary Wyrm, then the expansion beyond it: the Undervault hub and three looping regions (Kennel Yards, the Belfry, Rimeworks Aqueduct; 26 rooms in `src/world/rooms_expansion.ts`) with two more bosses that drop the double jump and slide relics. Off the Harpy Rookery is the Ashen Library (12 rooms in `src/world/rooms_library.ts`, with a giant staircase, walk-through furniture, and three enemies: the Rustling Tome, the Restless Chair and the Bone Librarian). Since 0.18.0 there are eight more zones (43 rooms in `src/world/rooms_depths.ts`) with six more bosses (all eight bosses after the Wyrm were reworked in 0.19.0): the Lichyard, Drowned Deeps, Serpent Temple, Warden's Gaol, Rimecrown Heights, Cinderworks, Mirror Vault and Archivist's Wing. Story text lives in `src/game/story.ts`. Vite + TypeScript + three.js. Pixel sprites at 384×224 in front of lit 3D backdrops.

The user is building this as a learning project. Explain changes briefly and keep the code readable.

## Hard rules

1. **No asset files.** All sprites, tiles, backdrops, UI, font, SFX and music are generated by code. Art goes through `PixelCanvas` in `src/gfx/`, sounds through the `SFX` table in `src/audio/audio.ts`, music in `src/audio/music.ts`.
2. **All content is original.** No characters, names, melodies or art from existing franchises. The folder name "Castlevania Clone" never appears in the game.
3. **Planning decisions are settled.** Don't change them without asking. See [docs/design-decisions.md](docs/design-decisions.md).

## Commands

```
npm run dev        # dev server
npm run typecheck  # tsc --noEmit (build does NOT type check)
npm run build      # production build to dist/
npm run check:rooms  # map check: overlaps, one-sided doorways, missing signs/items/enemies (add a room id to print it as text)
```

Use `npm.cmd` on Windows PowerShell if `npm` is blocked. Python 3.14 is available for helper scripts (bulk edits, checks): call it with `py` (or `C:\Python314\python.exe`), since bare `python` hits the Microsoft Store stub on this machine. Use it whenever it's the better tool. Debug: `window.game`, `#tour` (cycles all map cells), `#boss` / `#boss=hound` / `#boss=bellmother` (jump to a boss with 99,999 HP), `#hub` (the Undervault, Wyrm dead), `#relics` (same, with both relics), `#test=<enemy id>` / `#test=boss:<id>` / `#test` (enemy test chamber, also the enemy editor's TEST button, see `game/test_chamber.ts`; `#lab` is an alias), `game.input.script` (fake held inputs), `/editor.html` (map editor), F2 in game (edit the current room), `/enemies.html` (enemy editor; F3 in the game opens it), TEST ENEMY on the title menu (any enemy or boss).

## Gotchas that have bitten before

- Game logic is y-down, three.js is y-up: meshes sit at `(x, -y)`. Entities store center plus `hw`/`hh`.
- Any `THREE.Fog` near/far must include `+ CAM_DIST`, or everything fogs out.
- Sprites use `depthTest:false`. Layering is only `renderOrder` (wyrm 5 sits *below* tiles 6 on purpose).
- All character art faces right.
- Rooms must line up: doors on tile rows 8–11 (floor 12–13), vertical holes on columns 10–13.
- Jump ≈ 75 px high, ≈ 115 px running. Keep platform steps ≤ 4 tiles. The grapple is CV4-style since 0.17.0 (hold ATTACK, let go to launch; a full swing peaks a little above the ring), so the Wisp Gallery grate climb now needs the Sinew Coil (`relic_sinew`, a rubber-band stretch-and-sling on the chain).
- Rooms can be overridden by `src/world/room_edits.json`, which the map editor (F2 / `editor.html`) writes. If a room appears there, the JSON wins over its code in `rooms.ts`, including its position and size. Rooms made in the editor exist only in that file.
- Enemies can be overridden or added (variants) by `src/game/enemy_edits.json`, written by `enemies.html`. Enemy classes take a `kind` (base or variant id) and must read speed/ranges/abilities through `num()`/`can()` so variants work.
- Levers set persistent `Hunter.flags`. `RoomDef.gateFlag` / `drainFlag` open `G` tiles and drain water, `sealFlag` fills `N` tiles with snow. New `Hunter` fields need defaults so old saves still load.
- The Drawbridge must stay first in `buildBaseRooms()` (the title screen shows `defs[0]`). New games start in `START_ROOM` (the Ridge).
- A slide fits a one-tile gap; a double jump reaches ~140 px. Room gates built on these must stay out of reach without them (single jump ~79 px, crouch 24 px tall, running jump ~173 px across since the run became 1.5×). Paths everyone must take need 3 tiles of headroom. In water, Jump swims up and leaps ~67 px out at the surface, so tidal rooms (`RoomDef.tide`) can gate on high tide.
- Past its edge a room sees the neighbor room's real tile (`Game.tileOutside`, `''` = no room), so both sides of a doorway must be open. Straight above a room with no room there is open sky: no invisible ceilings. Outdoor rooms get a sky cell with `RB.sky()` plus a `SKY_SECRETS` entry. Broken `B` stones are saved in `Hunter.broken` and stay broken.
- Bosses must set `dead = true` when their death animation ends, or `update()` keeps running (the endless-explosions bug).
- Version numbers: every batch of changes gets a changelog entry in README.md and a bump of `package.json`'s version (MINOR per batch, PATCH for small fixes).
- Boss entrances lock the hero's controls (`Game.bossShow`). A boss's `enter` pattern must end by calling `g.bossTalk()`, or the controls never come back. It freezes the frame, then plays the `boss_<id>` scene in `SCENES` (story.ts), or starts the fight at once if there is none. Mid-fight scenes (a change of phase, a revive) start with `g.bossScene()` and must likewise end with `g.bossTalk('<scene>')`; the world doesn't update during the freeze or the talk, so the boss's pattern picks up where it left off. Dialogue is `Game.talk(scene, done)`; portraits are `<speaker>_<face>` frames from `gfx/art_portraits.ts`.
- Bosses: `RoomDef.boss` is a boss id from `BOSSES` (`game/bosses.ts`). Fights wall up the room's edge openings until the boss dies; `i` items in a boss room are its reward and stay hidden until then. Defeats are `boss_<id>` flags (`Hunter.beaten(id)`).
- `spawnEnemy` lives in `game/spawn.ts`, not enemies.ts, to avoid an import loop with `enemies_expansion.ts`.
- Furniture tiles `K` (bookcase) and `D` (table) are walk-through with a standable top (`Room.oneWayAt`), painted on their own layer behind the sprites. Rustling Tomes (`t`) must be placed on `K` tiles: they sleep there and fly out (`enemies_library.ts`). Chairs `n` (prop) and `a` (Restless Chair) face a table within 3 tiles. Door/hole alignment and the climb checks for those rooms are in [docs/level-design.md](docs/level-design.md).
- Ramps `/` and `\` rise one tile every two; along a row they pair up from the low end (low half, high half). Fill solid under them. `moveBody` stands a body on the slope by its center; `Room.blocks` lets a grounded body step up lips of 8 px or less where a ramp meets a landing.
- Hostile ents report how they hurt through `hitType()` (touch / melee / shot / magic), which decides what the shield does. A new enemy's lunge states go in its `lunges` list; fire-type `EnemyShot`s are magic.
- **Boss design rule (the user's, 0.19.0): no damage sponges, no minion swarms, nothing raining from the sky, no floating out of reach, no two bosses with the same trick.** Each boss has one learnable cycle tied to its zone that opens a window; pitch options to the user before building one. See [docs/player-mechanics.md](docs/player-mechanics.md).
- New bosses extend `BossBase` (`game/boss_base.ts`), one file each (`boss_<name>.ts`). HP is segments of 100; `strike()` takes a fixed quarter-segment and reports when the window's segment is spent, `clank()` is a blow that doesn't count. A boss lists what the whip can touch in `targets()` (body parts and arena props alike) and decides in `onStrike()`. Props it places go in `props`, things it spawns in `minions`; both die with it. `dyingTick` sets `dead`.
- Boss hooks: `Player.mount` (she hangs from a moving point), `Game.tideHold` + `setWater(y)` (the boss runs a tidal room's water), `View.roll` (PI = upside down), `Game.overlays` (drawn on the HUD canvas in play; keep hit-testing in `update`, not in the draw), `RoomDef.warp` (a breach to a room that isn't a neighbor).
- Variants can be written in code: `CODE_VARIANTS` in `game/data.ts` (a `base`, stats, `tune`, and a `shift` hue/saturation/lightness recolor). An entry with the same id in `enemy_edits.json` wins. A room places one with the base enemy's letter plus the variant id as the arg.
- `Input.mirror` swaps LEFT and RIGHT. `loadRoom` sets it from `RoomDef.mirror`; the Mirror Heart flips it mid-fight and must put it back (`settle`). It never flips a `game.input.script`.
- Glide gates are spike gaps of 20+ tiles (a running double jump covers about 13). The Pearl gate is a one-tile tunnel under water: sliding in water needs the Pearl.
- A save room's neighbors get an aura at the shared doorway (`Game.findSaveDoors` / `updateSaveAura`): motes, and the save theme on a second `Music` player while the zone song ducks.
- Story text uses `{NAME}`/`{CHILD}`/`{THEY}`/`{THEIR}` tokens for the chosen twin; `Game.showDialog` fills them in (`heroText`).
